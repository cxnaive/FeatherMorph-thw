# Peaceful Difficulty Regression

Result: **PASS**, 29 peaceful checks and 29 normal checks, 2026-10-10
(Asia/Shanghai). Both runs used the same release artifact.

Runtime: Java 25.0.4.1, local `Lophine-thw-20261009-versionfix`, Minecraft 26.2,
native protocol 776, PacketEvents **2.14.0**. Server and PacketEvents hashes are
unchanged from the [upgrade run](2026-10-10-lophine.md).

Policy: reject vanilla disguise requests in peaceful worlds when the entity's
NMS `isAllowedInPeaceful()` is false. The localized denial is sent before
bounding-box lookup, wrapper creation, or health scaling. This gate applies to
new disguise requests; it does not add automatic undisguise on world/difficulty
changes.
