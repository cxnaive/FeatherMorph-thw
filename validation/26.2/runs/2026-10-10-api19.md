Earlier failed attempts are retained separately and are not counted as passes.
They exposed equipment key case, pufferfish enum, and pose encoding mismatches.
Paired-client tests also exposed missing generic living-entity properties,
an Allay setter that ignores client-side writes, and Warden vanish guards that
were missing from the API 19 translation. These were corrected before the final
runs above.

Subsequent paired-client tests exposed a Shulker proxy relocation that reset
its shell height and produced an off-screen teleport render offset. The client
now preserves disguise shell state and suppresses only the proxy's render
offset; normal Shulkers retain vanilla relocation behavior. The paired-client
record includes API 19 shell-state/visual checks and API 17 legacy regressions.
