# Minecraft 26.2 Upgrade

`26.2/main` starts from upstream `26.1/main` at `3138dc32`. The original
`1.21.11/main` branch, including local commit `c36bb991`, is preserved.
Upstream is archived, so this is a local maintenance branch.

Build requirements: Java 25, Paper dev bundle `26.2.build.124-stable`, and
**PacketEvents 2.14.0**. The resulting plugin targets 26.2 only.

```bash
./gradlew build --no-daemon
```

Artifact: `build/libs/feathermorph-2.9.0-beta.2-thw.26.2-26.2-final.jar`.

## Changes

- Replace removed `EntityType.byString` with the entity registry's optional lookup.
  Invalid or unknown identifiers remain null, rather than falling back to a pig.
- Use `EntityTypes.END_CRYSTAL`, `Mob.getGoalSelector()`, `Entity.getRandom()`,
  and Adventure's `ClickEvent.openUrl()` for the changed APIs.
- Add cow, pig, cat, and wolf sound-variant metadata. Chicken's sound variant
  and AgeableMob's age-lock metadata are already present in the upstream base.
- Change wolf anger metadata from an integer to a long end time.
- Slime and magma cube now inherit AgeableMob via AbstractCubeMob. Update their
  values and watchers so size is index 18, after baby and age-lock at 16 and 17.
- Register a basic sulfur cube watcher with size, max-fuse, and from-bucket
  metadata. This adds the default disguise; it does not add a dedicated skill,
  content configuration, or a new user-editable size property.
- Recognize slime, magma cube, and sulfur cube as ageable for NBT inspection.
- Target API 26.2 and data-pack format 107.1; omit data-pack README files from
  the plugin JAR so Minecraft does not parse them as resource identifiers.
- Only report waypoint transmission after the manager actually registers it.
- Reject vanilla disguise requests in peaceful worlds when NMS
  `isAllowedInPeaceful()` is false, with a localized explanation. This check runs
  before bounding-box queries, wrapper creation, and health scaling, preventing
  26.2's temporary-monster creation errors without bypassing spawn restrictions.

## Lophine And Folia

The inspected core is `../thw_servers/26.2/Lophine`, branch
`restore-linear-26.2`, source HEAD `ee77864`, running build
`Lophine-thw-20261009-versionfix`.

| Previous compatibility behavior | Decision for this core |
| --- | --- |
| Optional waypoint reflection fallback in `c36bb991` | Do not transplant. `ServerLevel.getWaypointManager()` exists and returns a `FoliaServerWaypointManager`; track, untrack, and transmitters are public. |
| Entity/region schedulers and owner-region checks | Keep. Region ownership is still required in 26.2. |
| `Bukkit.isOwnedByCurrentRegion` and raw-handle ownership checks | Keep upstream's existing fixes `123cfb5e` and `1e85e72f`; both are in the 26.1 base. |
| `NmsRecord.ofPlayer()` using `CraftPlayer.getHandle()` | Keep. The inspected CraftPlayer explicitly omits ownership checks for player handles; this does not permit arbitrary access to other entities. |
| AI modification disabled by default on Folia | Keep. The upgrade does not establish that this feature is safe across regions. |

Lophine's `experiment.command.enable_waypoints_and_waypoint_command` defaults to
false. When disabled, track/untrack are no-ops. FeatherMorph now leaves its
transmitting flag false after a refused registration, allowing a later retry.
Enabling the server option is a separate operational choice. No existing server
configuration was changed.

These conclusions apply to the inspected modified Lophine build. They do not
establish compatibility with Folia builds that still remove the waypoint API.
Player-disguise waypoint connections across regions remain untested.

## Client Command API 19

The plugin and the maintained 26.2 client now share protocol library
`6ea1669075` (API 19). Disable the client's protocol compatibility mode and
reconnect to use API 19. Existing configurations retain their saved option.
Compatibility mode still reports API 17 and uses the older animation messages.
The server replies with each session's API so the client chooses the matching
message semantics.

API 19 animations synchronize temporary property overlays and explicitly
discard them when the animation ends. Persistent property updates/discards
clear the corresponding overlay; refreshing client state restores active
animations. Existing animation queues and server-side renderers are retained.
Vanished wardens retain their temporary invisibility when sniff/roar actions or
conditional resets are requested, matching the server renderer's guards.
BODY and SADDLE equipment slots are encoded for API 18/19 clients and filtered
out for older clients. API 19 supports persistent property discard; older
clients receive the default property value instead.

The paired client also retains temporary properties across entity rebuilds,
caches updates/discards before a syncer exists, and clears caches on disconnect.
Minecraft network protocol 776 and FeatherMorph command API 19 are independent.

## Validation

The repeatable [26.2 validation suite](../validation/26.2/README.md) follows
Aiyatsbus's isolated Folia server, native protocol bot, independent probe, and
evidence retention approach. It uses pinned native protocol 776 sources without
ViaVersion. The probe is packaged separately and excluded from the release JAR.

Verified on local Lophine with PacketEvents 2.14.0:

- Plugin build, API/Folia descriptors, three enabled built-in data packs, and
  exclusion of test classes from the release artifact.
- Six registry edge cases and 23 metadata indices and serializer IDs compared
  independently with the running NMS implementation.
- Waypoint registration disabled/enabled/cleanup in all three worlds, restoring
  the original server flag afterwards.
- Real player `/morph` and `/unmorph`, owner-region state checks, and observer
  spawn/metadata packets for cow, pig, chicken, cat, wolf, sheep, mooshroom,
  nautilus, evoker, slime, magma cube, and sulfur cube.
- Observer reconnect while disguised as a cow; nondefault slime and magma cube
  size 3 arrives at index 18 with the integer serializer.
- Peaceful evoker/slime/magma cube denial preserves the player's current disguise,
  health, dimensions, and observer entity. Allowed forms continue to work with
  bounding-box modification and space checks enabled.
- Normal server shutdown, no FeatherMorph errors or region-thread violations.
- Actual V3 handshakes for API 19 and API 17, matching animation messages,
  BODY/SADDLE serialization/filtering, and property discard/default restoration.

See the [retained run record](../validation/26.2/runs/2026-10-10-lophine.md).
Peaceful-policy regression results are recorded
[separately](../validation/26.2/runs/2026-10-10-peaceful.md).
API 19 and paired real-client checks are recorded in the
[protocol upgrade run](../validation/26.2/runs/2026-10-10-api19.md).
The separate [gameplay matrix](../validation/26.2/runs/2026-10-10-gameplay.md)
now exercises all ten active skill types and 27 passive ability types, with
representative real-client synchronization checks. It found and fixed repeated
sonic knockback, a ghast charge-delay/default target mismatch, and discarded
chat-renderer output. Existing generated ghast settings migrate once; customized
projectile options are preserved.
The native smoke suite does not render clients or test other plugins, cross-region
player-disguise waypoints, or every custom skill/ability option combination.
PacketEvents's optional GitHub update check may receive HTTP 403; the
suite records that exact external warning separately and still fails on other
exceptions or plugin errors.
